# Lab 2 - Python Fluency

## Objectives

This lab focuses on writing clean Python functions and using Python's standard library effectively.

## Tasks Completed

1. Implemented a word frequency counter using dictionaries.
2. Reimplemented the same functionality using `collections.Counter`.
3. Flattened a nested list using nested loops.
4. Flattened a nested list using a list comprehension.
5. Calculated the mean of numbers stored in a text file with proper exception handling.
6. Demonstrated all functions using an `if __name__ == "__main__":` block.
